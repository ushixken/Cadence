# GB9 — Block Hardening

Version 3 persistence remains the sole durable Block/Group representation. Serialization validates first, orders top-level identity tables deterministically, preserves Definition `recordOrder`, semantic records, transforms, layers, properties, and all persisted topology identities, and never emits traversal paths, expanded records, proxies, snap/track state, grips, measurement results, annotation caches, triangulation, or generated hatch strokes. Strict load validation rejects unknown runtime fields, duplicate identities across every persisted namespace, malformed topology and transforms, stale references, invalid orders, cycles, and resource-limit violations atomically. Valid older v3 documents continue to normalize missing additive Group and Definition tables to empty state.

All persisted IDs share the document allocator and global validation namespace. Runtime semantic IDs are path-qualified strings produced only by `CaderactBlockTraversal`; they never enter persistence or allocation. Definition removal rejects model-space or nested references, never cascades, and unused removal remains one exact history operation.

Traversal is deterministic from Definition `recordOrder`, bounded at depth 32, 100,000 semantic leaves, and 1,000,000 visits, and performs no mutation or persistent allocation. `CaderactBlockTraversal.bounds` is the shared renderer-neutral conservative bounds authority. It derives current transformed semantic leaves, accepts member-layer visibility, covers curves, Polyline, Region/Hatch boundaries, Text, and Dimensions, and reports deterministic work counts. Bounds are an early-rejection aid, never authoritative geometry.

No derived cache is introduced. BlockEdit, layer/property changes, transform replacement, undo/redo, definition removal, and persistence replacement therefore invalidate naturally by current-state derivation. Pointer interaction may use conservative bounds before semantic expansion where profiling demonstrates a benefit; broad per-frame caching remains intentionally deferred because explicit invalidation complexity is not justified by current deterministic workloads.

Renderers remain downstream consumers of ordinary renderer-neutral semantic records. They do not resolve Definitions, inspect nesting, compose transforms, or generate Block-specific topology. Path-qualified transformed record IDs also keep repeated and nested Text/Dimension annotation keys distinct. Region loops, Hatch boundaries/pattern metadata, Text, and Dimension definitions remain authoritative and presentation remains derived.

Outer/member visibility and lock policies are shared with GB8. Member layer metadata is retained; the beta property model uses existing member ByLayer/explicit properties and does not invent DXF BYBLOCK inheritance. Groups remain relationship metadata around model-space records and cannot be bypassed by nested Block semantics. The bounded DXF BLOCK/INSERT boundary was completed in GB10, and the combined Groups + Blocks track is declared beta-ready by the GB11 adversarial audit.
