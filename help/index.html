Caderact Help

Caderact Help is the official user documentation for Caderact, a browser-based CAD/BIM application.

How this documentation is organized

Documentation is grouped into sections that will grow as Caderact does: Getting Started, Workspace, Commands, Drafting, Reference, and Troubleshooting. A section only contains published pages once the corresponding Caderact functionality has been implemented, tested, and accepted. Sections without content yet are shown as upcoming rather than left unlisted, so this Help site is always honest about what's here today and what's still on the way.

Documentation grows with Caderact

As commands and features stabilize, their documentation is added here. Functionality that's still under active development — including current in-progress work on the Line command — is intentionally left undocumented until it's finished and accepted, so this Help site never describes behavior Caderact doesn't actually have yet.
