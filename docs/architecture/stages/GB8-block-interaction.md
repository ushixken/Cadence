# GB8 — Block Interaction

A committed Block Instance remains one model-space selection. Hit testing expands its currently visible semantic members only as transient proxies; click, Window, Crossing, nested geometry, and Group resolution always return the outer Instance ID. Window requires every visible proxy belonging to an Instance to be contained, while Crossing requires any proxy hit. Hidden outer layers suppress the Instance entirely; hidden member layers suppress only those members. Locked outer Instances remain renderable precision references but are excluded from editable selection and grips.

The conservative Block grip is its insertion point. It owns the persisted insertion feature ID and translates the outer Instance through `GeometryTransform`, preserving the Instance ID, Definition reference, rotation, scale, and mirrored state. Definition-member grips are never exposed.

`CaderactBlockTraversal` produces bounded semantic leaves on demand. Visible eligible leaves are transformed once through the composed `CaderactSimilarityTransform` and enter the existing `SnapResolver`, intersection, and Object Snap Tracking pipelines as native geometry. Their runtime IDs are path-qualified by outer and nested Instance IDs plus the member ID, so repeated Definitions cannot collide. Direct P9 snaps retain precedence over tracking; the raw custom cursor remains at the physical pointer while marker, HUD, preview, tracking, and acceptance use the resolved point. Region, Hatch, Text, and annotation presentation primitives do not gain new snaps.

Minimum-distance commands traverse visible transformed Line, Circle, Arc, and Polyline leaves and reuse the existing native measurement authority for point-to-Block, Block-to-record, and Block-to-Block comparisons. Results may carry transient runtime semantic references. Heterogeneous whole-Block radius, diameter, length, or area remains unsupported. Member locks follow normal locked-reference behavior; they do not expose editable subobjects.

Traversal retains the GB3 depth, semantic-record, and visit limits and introduces no persistent expansion cache. BlockEdit, layer changes, copy, and document replacement therefore affect interaction immediately. Runtime paths, hit proxies, snap references, tracking acquisitions, measurement results, and grip state are never serialized. GB9 can harden performance, richer diagnostics, and remaining interaction edge cases without changing this ownership model.
