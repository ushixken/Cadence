# GB7 — Block Explode and Copy

Normal `Copy` now treats a model-space Block Instance as a reference record: it allocates a fresh record ID and insertion-feature ID while preserving the Definition reference, transform, layer, and explicit object properties. Move, Rotate, Scale, and Mirror use the shared geometry-transform authority and retain the Instance identity and Definition reference. Group Copy consequently copies Block Instances and complete Groups through the existing atomic copy publication path without duplicating Definitions.

`Explode` (`X`) accepts one or more selected, editable, ungrouped model-space Block Instances. The document gateway validates the complete selection, recursively expands each Instance through `CaderactBlockTraversal`, applies each fully composed `CaderactSimilarityTransform` through `GeometryTransform.similarityRecord`, regenerates every persistent identity through the document allocator, then creates all native leaves and removes all source Instances in one transaction. Definitions are retained even when unused. Successful output selection contains only the new model-space record IDs; cancellation or any traversal, transform, validation, or publication failure leaves document, selection, and history unchanged.

Expansion remains semantic: Line, Circle, Arc, Ellipse, Polyline, Region, Hatch, Text, and Dimension records remain their native types. Region/Hatch topology, Polyline vertices, annotation points, and all ordinary features receive fresh IDs; renderer primitives, traversal paths, and runtime semantic IDs never persist. Nested rotation, positive uniform scale, and reflection are composed before transformation. Existing Region orientation, Hatch pattern, readable Text, and non-associative Dimension snapshot policies remain owned by their shared semantic transform authorities.

Definition-member layers and explicit properties are retained. Hidden members are preserved rather than filtered by the viewport, so their model-space outputs remain controlled by the same hidden layer. Locked member layers likewise remain valid output state, while a locked top-level Instance is not editable and is rejected. Explicit Explode rejects grouped Instances until they are ungrouped, avoiding an implicit Group-topology rewrite.

Explode is one history entry: Undo restores the exact source Instances and removes outputs; Redo restores the exact output records and feature identities. Native persistence contains Definitions, remaining Instances, and exploded semantic records only. Exploded outputs immediately re-enter existing native selection, grip, Osnap, Track, and measurement authorities. Unexploded Block Instances remain excluded from Osnap, Track, and measurement.

GB8 may build interaction integration on the stable Block Instance transform support and atomic Explode gateway. Richer BlockEdit member picking, local workspace history, drawing creation, Properties editing, rename, Set Base Point, direct Block Osnap/Track/measurement traversal, and DXF BLOCK/INSERT remain deferred.
