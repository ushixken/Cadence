# Caderact Help

Caderact Help is the official user documentation for Caderact, a
browser-based CAD/BIM application.

## How this documentation is organized

Documentation is grouped into sections that will grow as Caderact does:

- **Getting Started** — orientation for new users
- **Workspace** — the Caderact interface and viewport
- **Commands** — reference pages for individual commands
- **Drafting** — drafting concepts and workflows
- **Reference** — supporting reference material
- **Troubleshooting** — solutions to common issues

A section only contains published pages once the corresponding Caderact
functionality has been implemented, tested, and accepted. Sections without
content yet are shown as upcoming rather than left unlisted, so the
documentation structure is honest about what's here today and what's
still on the way.

## Documentation grows with Caderact

As commands and features stabilize, their documentation is added here.
Functionality that is still under active development — including current
in-progress work on the Line command — is intentionally left undocumented
until it's finished and accepted, so this Help site never describes
behavior Caderact doesn't actually have yet.
